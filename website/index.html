DejaView — A Java frontend framework compiled to JavaScript

Bring modern web development capabilities to Java using a dedicated frontend runtime, component-based architecture and a reactive rendering engine.

Philosophy

  • Java is primary. The entire stack targets JDK 25; no alternative language or compilation target.
  • JavaScript only browser target. WebAssembly is out of scope.
  • Framework stays DOM-free. `dejaview-core` contains no browser APIs; `dejaview-dom` provides platform-neutral DOM contracts.
  • Component model first. `Component`, `AbstractComponent`, `ComponentView`, `RenderNode` give reusable, composable UI units.
  • Reactivity is granular. Signals, effects and computed values drive updates without full-tree re-renders.

Feature Highlights

Runtime Bootstrap

TeaVM 0.16.0 compiles Java → JavaScript at build time; the browser bundle runs in the same environment as native JS.

Core Abstractions

Immutable view model (`View`, `ElementView`, `TextView`, ...), attributes, properties, event bindings.

Reactivity Engine

Signals, Effects, Computed, batching, FIFO scheduling, cleanup on dispose.

Renderer & Reconciliation

Explicit render tree via sealed `RenderNode` variants; positional reconciliation preserves nodes.

Component System

`Component`, `AbstractComponent`, `ComponentView`, lifecycle hooks, resource ownership.

Styling Compatibility

Plain `class`/`style` attributes; works with Bootstrap, Tailwind CSS, daisyUI without a proprietary pipeline.

Getting Started

  1. Install Maven Wrapper + Java 25.
  2. Build: `./mvnw clean verify` (all modules).
  3. Run example: `./mvnw -Pe2e -pl examples/counter -am verify` (Chromium E2E).
  4. Serve the static site: `python3 -m http.server 8080 -d website/`.

Architecture Overview

The project follows the long-term design documented in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and recorded in ADRs [ADR-0003 … ADR-0014](docs/ADR/README.md). Key points:

  • dejaview-core — immutable view model, `Property`, `Lifecycle`, `Preconditions`.
  • dejaview-reactivity — signals, effects, computed, scopes, batching, scheduler.
  • dejaview-dom — DOM contracts, render tree, `DomTreeReconciler`, TeaVM JSO adapter.
  • examples/* — Java → JavaScript browser examples compiled by TeaVM.

Core API

All public classes live under the `io.dejaview.core` package. The most relevant ones are:

  • io.dejaview.core.Component — functional interface: render(), default name(), no-op close().
  • io.dejaview.core.AbstractComponent — base class that owns resources via ResourceRegistry; implements Component. Subclasses cannot override close().
  • io.dejaview.core.ComponentView — record holding a Supplier factory; of(Component) mounts an existing instance.
  • Views.component(Supplier) / Views.componentFactory(Supplier) — convenience factories.

Reactivity

Core primitives:

  • Signal – mutable state (get/set/update).
  • Effect – synchronous observer that tracks reads and reconciles DOM. Disposed with the mounted tree.
  • Computed – lazy, cached value invalidated push‑based. Detects cycles.
  • ReactiveScope – groups disposal of effects/computed/child scopes.

Components

See [Component.java](dejaview-core/src/main/java/io/dejaview/core/Component.java) and [AbstractComponent.java](dejaview-core/src/main/java/io/dejaview/core/AbstractComponent.java). Components own their resources through own(T) / onDispose(Runnable) registered with ResourceRegistry.
