    How this works. Examples are written in Java against the real DejaView API, compiled to JavaScript with TeaVM at build time, and executed in the preview iframe exactly like a production deployment.

    In-browser editing and recompilation arrive with the development-server milestone (see ROADMAP). Until then the editor is an interactive viewer: you may edit freely — Run executes the last compiled build.
